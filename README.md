Идея проекта заключается в разработке десктопного приложения менеджера паролей.
В приложении планируется реализовать такие функции, как:
1. генерация паролей (выбор длинны пароля, символов, цифр и специальных знаков);
3. ведение нескольких записей в одном файле;
4. сохранение файла с записями с выбором метода шифрования и паролем;
5. открытие файлов с записями, после ввода пароля.
